# Правила для агента

Интерфейсы в этом репозитории собираются только из компонентов shadcn/ui.

- Приложение лежит в `web/` (Next.js + Tailwind, `web/components.json`). Все команды shadcn запускать с `--cwd web` или из папки `web/`.
- Перед тем как писать UI, найди подходящие компоненты и блоки через MCP-сервер `shadcn` (поиск, просмотр, примеры). Если MCP недоступен, используй CLI: `npx shadcn@latest search`, `view`, `docs`.
- Добавляй компоненты командой `npx shadcn@latest add <name> --cwd web`, не переписывай их вручную.
- Готовые компоненты лежат в `web/components/ui/`. Меняй их только когда без этого никак.
- Цвета, радиусы и шрифты бери из CSS-переменных темы, а не из захардкоженных значений.
